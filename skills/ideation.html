Ideation

Turn open questions into a useful field of possibilities.

Ideation is where every branch starts: you take a loose question and grow several honest options before choosing one. At Level 1 you practise one idea-making task at a time and keep the reviewed result.

See Level 1 tasks Growth path

Level 1 tasks

What you'll practise.

Four individual skills from the readiness registry. Each ends with one reviewed output you keep.

Ideation

You'll need
Problem brief, target users, constraints and decision criteria
Done when

Supported by
design-lab

SK-004 · StrategyAvailable

Foresight

You'll need
Defined horizon, dated signals, uncertainties, constraints
Done when
Multiple plausible scenarios distinguish facts from hypotheses and identify implications, signposts, and actions.
Supported by
Native scenario reasoning + business-planning scenario support + web research
Next action
Run one bounded foresight exercise; dedicated foresight implementation not inspected.
SK-026 · CommunicationAvailable

Storytelling

You'll need
Audience; key message; source material; narrative purpose
Done when
Narrative has a coherent sequence, evidence-supported message and an appropriate call to action.
Supported by
ChatGPT; writing-strategy
Next action
Apply one narrative strategy to a real brief and review the resulting story.
SK-031 · MusicAvailable

Lyrics
