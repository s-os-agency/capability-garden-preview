Curiosity

Follow the signal behind the obvious answer.

Curiosity is the habit of looking one layer deeper. At Level 1 you learn to find the right sources, collect them cleanly and judge how far each one can be trusted.

See Level 1 tasks Growth path

Level 1 tasks

What you'll practise.

Four individual skills from the readiness registry. Each ends with one reviewed output you keep.

SK-007 · ResearchAvailable

Discovery

You'll need
Retrieval question, concrete anchors, relevant source access
Done when
Relevant source families are examined or explicitly unavailable; authoritative artifacts and material context gaps are identified.
Supported by
Data Analytics gather-business-context
Next action
Run discovery for one bounded question and retain the source register.
SK-008 · ResearchAvailable

Source collection

You'll need
Located sources; access rights; retrieval scope
Done when
Sources retain URLs/identifiers, dates, authority, relevant extracted facts, and access limitations.
Supported by
gather-business-context + available web/connector retrieval tools
Next action
Collect a representative evidence set and verify retrieval accuracy.
SK-009 · ResearchAvailable

Evidence assessment

You'll need
Collected sources, material claims, assessment criteria
Done when
Evidence is assessed for authority, freshness, scope, and directness; conflicts and unsupported claims remain visible.
Supported by
gather-business-context evidence reconciliation + native evaluation
Next action
Review a sample claim set against its underlying sources.
SK-019 · DataConnected

Collection

You'll need
Authorized source workbook; exact tab names and bounded ranges
Done when
Collect a representative dataset with IDs, source references, dates and row-count reconciliation.
Supported by
Google Drive / Sheets connector
Next action
Read a complete sample and reconcile source and destination counts.
