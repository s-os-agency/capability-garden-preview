Level 1 · open now

Prototype

Make the possibility tangible enough to test.

Prototype turns a chosen idea into something people can click, read or hold. At Level 1 you build one small, working piece and check it in a real browser or on a real screen.

See Level 1 tasks Growth path

Level 1 tasks

What you'll practise.

Four individual skills from the readiness registry. Each ends with one reviewed output you keep.

SK-016 · DesignAvailable

Prototyping

You'll need
Agreed flow and design, target repository, frontend runtime and browser access
Done when
Run a usable prototype of the primary journey, including interaction states and responsive behavior; retain browser evidence.
Supported by
frontend-app-builder
Next action
Locate the existing prototype repository and exercise one complete journey.
SK-014 · DesignConnected

UX/UI

You'll need
User tasks, navigation requirements, design constraints and accessible Figma file
Done when
Deliver a complete primary user flow with clear hierarchy, interaction states and an accepted usability review.
Supported by
interface-design; Figma
Next action
Assess one existing primary user flow and retain its usability acceptance results.
SK-015 · DesignConnected

Visual design

You'll need
Approved brand direction, typography, colors, assets and target screens
Done when
Deliver visually consistent screens with readable typography, appropriate contrast and no clipping or overlap, accepted by Seif.
Supported by
frontend-design; Figma
Next action
Review a representative screen against the brand and retain screenshots and acceptance.
SK-037 · Engineering & automationConnected

Coding

You'll need
Target repository; repository instructions; acceptance criteria; language runtime
Done when
Implement one scoped change in the intended repository; review the diff and pass relevant checks.
Supported by
fullstack-dev; exec_command; apply_patch; GitHub
Next action
Choose an existing repository and validate a small authorized change against its acceptance criteria.
